
# Patient Summary – Python Capstone Project

## Overview

This project is a beginner-friendly Python capstone that generates a formatted patient summary from user input. It demonstrates the use of variables, user input, string formatting, and basic data cleaning techniques.

## Project Objective

Create a program that captures a patient's details and displays a clear, multi-line summary containing:

* Name
* Age
* Condition
* Status

## Technologies Used

* Python 3

## Features

* Accepts patient information through the command line.
* Formats names and conditions using title case.
* Removes unnecessary whitespace from user input.
* Displays a clean and readable patient summary.

## Example Output

```text
Patient Summary
---------------
Name: John
Age: 35
Condition: Malaria
Status: Admitted
```

## Learning Outcomes

Through this project, I practiced:

* Working with `input()`
* Variable assignment
* String methods (`strip()`, `title()`)
* f-strings for formatted output
* Creating readable console applications
